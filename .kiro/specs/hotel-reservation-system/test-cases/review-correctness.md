## 3. 問題がなかった主な確認

- 料金の単価：P-01 の整数式で、01 の基本料金（7タイプ）、子どもの半額、率の合算（掛け合わせない）、下限（−4900／−5000／−5100bp、割増を含めた合算）、人数割と連泊割の段階、判定人数（2名1室→2、10名10室→0、10名5室→10、11名6室→10）、早期割が一致した。6.19 の計算例（21,500／10,700／3,300／1,600／61,900／宿泊税 600）も再現できた
- 宿泊税：切り捨て前の税抜単価で判定するため、境目（4,999／5,000／19,999／20,000）、5,263円×9,500bp（4,999.85 → 0円）、プレミアム 19,550円（→ 200円）、子ども 4,875円（→ 0円）がすべて正しい
- 04 の金額：予約A〜I の単価・合計・支払い済みの額、変更の差額（4,800／22,800／42,600／11,400／13,200／9,800／40,200／26,000／2,700／25,000／85,200）が一致した。キャンセル料と返金額（28,000／56,800／28,400／31,800／34,600／26,400／46,200）、団体（73,800／184,500／369,000、返金 190,500／301,200／0、部分キャンセル 16,500）、合算と減った後の団体（31,680／63,360）、早期割の団体（327,000、返金0）も一致した。ノーショー（28,000、返金 56,800、1泊の予約は返金0）と、宿泊税の返金・付け替え（P-06 の例5つ）も一致した
- 05 の金額：単価表 U1〜U17、有償アップグレード（6,400／8,000／12,400／10,600／16,800）、下位タイプの返金（6,400。版2の 4,200円にならないこと、67,600）、時間外（2,000／4,000／6,000）、要精算 188,200円が一致した
- 日時の境界：無料期限（14:59・15:00・15:01、ちょうどの時刻は無料）、団体の段階の 0:00（10/31・11/23・11/29）は仕様どおり。営業日（0:59／1:00）、ノーショーの判定と延長の上限（翌日 12:00）、9:00 と前日 10:00 の処理、3年（ちょうど・前後、うるう日は要確認）も正しい。24時間・1時間・7日・12時間・15分（10:14 と 10:16）、清掃の空き2時間ちょうどは作らないこと、365日（2027-11-10／2027-10-19）、7泊を超えた8日目の要精算、故障中の終了予定日と翌日の戻りも仕様どおり
- 暦：曜日の表記 83か所に誤りはなかった。祝日（2026-09-21 敬老の日、9-22 国民の休日、11-03 文化の日、11-23 勤労感謝の日、2027-01-01、02-11、03-21 春分の日と 03-22 振替休日、05-03〜05-05）と祝前日の扱い（土曜と祝前日が重なっても1つ）も実際の暦と合っている
