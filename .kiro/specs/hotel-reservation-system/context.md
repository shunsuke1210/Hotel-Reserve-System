# Context: hotel-reservation-system（用語の定義）

要件・設計・画面の文言で解釈が分かれるおそれのある用語を固定する。要件書（requirements.md）の用語はこの定義に従う。

最終更新：2026-10-16

## 日付・時刻

| 用語 | 定義 | 注意 |
|---|---|---|
| 宿泊日 | 客がチェックインする日付。「その宿泊日の夜」に泊まる | 0:00〜1:00（最終チェックイン25:00まで）に受け付ける当日の予約は、**前日の日付**を宿泊日とする |
| 夜 | 宿泊日の夜1回分。料金・在庫・売上は夜ごとに数える | チェックアウト日の夜は含まない |
| 今日から365日以内 | 宿泊するすべての夜の宿泊日が、今日の日付に365日を足した日以前であること | 例：今日が 2026/10/16 なら 2027/10/16 の夜まで |
| 祝前日 | 国民の祝日、および法律で定める休日（振替休日・国民の休日）の前日 | 例：月曜が祝日なら日曜の夜が割増になる。連休中は休日の前日がすべて該当する |
| 早期割の期限 | 到着日の暦の上で3か月前の同じ日（その日を含む）。その日が存在しない月は、その月の末日 | 例：5/31 到着 → 2/28（うるう年は 2/29） |
| 日本時間 | 表示する時刻はすべて日本時間。自動処理（9:00の状態更新、25:00のノーショー判定、前日10:00の案内）も日本時間で行う | — |

## 人数・部屋

| 用語 | 定義 | 注意 |
|---|---|---|
| 大人／子ども／幼児 | 大人＝中学生以上、子ども＝3歳〜小学生、幼児＝2歳以下 | 会員本人は生年月日とチェックイン日から判定し、同行者は自己申告。12歳の小6と中1は区別しない |
| 定員 | 1室に泊まれる**大人**の上限（ソファーベッドを含む） | 幼児は含めない。子どもを含めるかは予約者に任せる |
| 基準人数 | ソファーベッドなどの補助ベッドを除き、通常のベッドで寝られる人数（全タイプ2名） | 人数割の判定人数にだけ使う。定員とは別の値 |
| 宿泊人数 | 予約全体の人数。幼児を含む全員 | 人数割・宿泊税・名簿で使う |
| 判定人数 | 人数割の段階を決める人数。宿泊人数 − max(0, 予約した部屋の基準人数の合計 − 宿泊人数) | 0以下なら人数割は0% |
| 割り当て | 予約に具体的な部屋番号を結びつけること | 予約時に自動で行う。フロントが変更・入れ替えできる |
| 部屋替え | 宿泊客の都合による部屋の変更 | 認めない。フロントによる割り当ての変更（チェックイン前、またはチェックイン後の故障時）は部屋替えに含めない |

## 予約・支払い

| 用語 | 定義 | 注意 |
|---|---|---|
| 決済待ち | 予約者が支払いに進んでから、予約が確定するまでの状態。部屋を15分間確保する | 1人の会員につき同時に1件まで |
| 予約確定 | 事前決済では決済が終わった状態、現地払いでは会員が確定の操作をした状態 | 料金はこの時点で固定する |
| 事前決済 | 予約時に、登録したカードで全額を払う方法 | 変更・キャンセルの差額は、その時点でカードで処理する |
| 現地払い | ホテルで精算する方法。カードの登録（カード保証）が必須 | チェックアウト時に精算。7泊を超える滞在は8日目から7泊ごとにも精算する |
| カード保証 | 現地払いの予約で、会員登録時に登録したカードを、キャンセル料やノーショーの料金の請求先とすること | 会員は全員カードを登録している（必須）。保証にしただけでは請求しない |
| 団体 | 予約期間中に一度でも5室以上になった予約。同じ会員の、夜が重なる予約は室数を合算して判定する | 一度団体になったら、室数が減っても個人には戻さない |
| 1泊分 | キャンセル料の単位。取り消した部屋・人の、取り消した最初の夜の宿泊料金（税込みの表示額） | 朝食・宿泊税を含めない。消費税・宿泊税を上乗せしない |
| 部分キャンセル | 泊数・室数・人数を減らす変更、および早期チェックアウト | 変更した時点のキャンセル規定を適用する |
| ノーショー | 到着日の25:00（翌日1:00）までに連絡なくチェックインしなかった予約 | フロントは判定を延ばせる。判定後に到着した場合は取り消せる |

## 客室の状態

| 用語 | 定義 | 注意 |
|---|---|---|
| 空室の清掃グループ | 清掃可・清掃中・点検待ち・清掃完了 | チェックアウト後の部屋が入る |
| 連泊グループ | 清掃有（連泊）・清掃中（連泊）・点検待ち（連泊）・清掃完了（連泊） | 実際に連泊している部屋だけが入る。チェックインした夜は「チェックイン済み」 |
| チェックイン済み | フロントがチェックインの操作をした部屋の、翌朝9:00までの状態 | — |
| チェックアウト待ち | 今日チェックアウト予定の客が滞在している状態 | 毎朝9:00に自動で設定する |
| 来客なし | ノーショーと判定された予約が割り当てられていた部屋 | 毎朝9:00に自動で設定する。清掃員が確認して清掃完了にする |
| 故障中 | 終了予定日まで販売・割り当てができない状態 | 終了予定日の翌日から在庫に戻る |

## 売上・集計

| 用語 | 定義 | 注意 |
|---|---|---|
| 売上 | 税抜（消費税・宿泊税を除く）。宿泊した夜ごとに計上する。キャンセル料は別の項目として含める | — |
| 販売した室数 | その夜に確定している予約の室数 | キャンセルされた分と、ノーショーで取り消された2泊目以降は含めない |
| 稼働率 | 販売した室数 ÷（総室数 − 故障中の室数） | — |
| 客室単価（ADR） | 宿泊料金の売上 ÷ 販売した室数 | 朝食・キャンセル料を含めない |
| RevPAR | 宿泊料金の売上 ÷ 販売可能な室数（総室数 − 故障中の室数） | 朝食・キャンセル料を含めない |

## 追加した用語（2026-10-16）

| 用語 | 定義 | 注意 |
|---|---|---|
| お知らせ | 予約状況チャートに表示する、フロント向けの通知。解決していない件数を赤丸のバッジで示し、「解決」ボタンで解決済みにする | 出すのは ①連泊できる部屋がなく在庫なしになったとき、②複数室の予約が同じ階に収まらなかったとき（手動の移動・入れ替えの結果を含む）、③同じ部屋でチェックアウトから次のチェックインまでの空きが2時間未満になったとき |
| アーリーチェックイン／レイトチェックアウト | 15:00より前（12:00・13:00・14:00 から）のチェックインと、12:00より後（13:00・14:00・15:00 まで）のチェックアウト。オプションとして1室1時間1,000円（税込み） | 割り当てに特別な条件はつけない。料金はいつも現地で精算する |
| 有償アップグレード | 宿泊客の希望で、フロントが上位の客室タイプに移すこと。差額は変更時点の料金表で計算し、現地で精算する | ホテル都合の移動（無償）とは、移すときに選び分ける |
| 宿泊税の宿泊料金 | 宿泊税の判定に使う、1人1泊の税抜の素泊まり料金（割増・割引を適用した後） | 朝食・アーリー／レイトの料金・消費税は含めない。5,000円未満は課税しない |
| 最終宿泊日 | 会員が最後に宿泊した夜の宿泊日 | アカウントを削除する時期（3年後）の起点 |
| 有効な会員 | 退会も削除もしていない会員 | メールアドレス・電話番号の重複は、有効な会員の間でだけ確認する |

## 設計で使う用語（2026-10-16）

| 用語 | 定義 | 注意 |
|---|---|---|
| 営業日 | 1:00 を日の境目とする日付。0:00〜0:59 は前日の営業日 | 当日予約の締め切りとノーショーの判定に使う。365日の判定は暦の日付を使う |
| 確保（ホールド） | 支払いへ進んだ時点で、割り当てた部屋の夜を15分間押さえること | room_nights の HOLD の行。期限を過ぎた確保は在庫の判定で空きとみなす |
| 料金の版 | 料金表（率・朝食・時間外・宿泊税の区分・基本料金）のひとまとまり。変更のたびに新しい版を作る | 確定済みの予約は、夜ごとに予約した時点の版を使い続ける |
| 料金の控え | 予約した夜ごとに保存する、版・基本料金・割増率・早期割の対象かどうか | 変更のときも、もとの夜は控えのまま計算する |
| 明細 | 予約の請求を項目ごとに分けた行（宿泊料金、朝食、時間外、アップグレード、キャンセル料、宿泊税など） | 変更のたびに古い明細を取り消し扱いにして作り直す。残高＝有効な明細の合計−入金＋返金 |
| 警告 | 状態から決まる、フロントへの注意（故障中の部屋への割り当て、期限切れの故障中、要精算、送れなかったメール） | お知らせと違い保存しない。状態が解消すると自動で消える |
