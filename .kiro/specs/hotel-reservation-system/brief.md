## 3. スコープ（Boundary Candidates）

**含める**
- 会員制の Web 予約（多言語）と、事前決済またはカード保証
- フロントによる予約登録（予約状況チャート）
- 客室の自動割り当てと、フロントによる手動変更・入れ替え
- チェックイン／チェックアウト
- 清掃状況の管理
- 宿泊者名簿
- 会員（顧客・リピーター）の管理
- 売上・稼働率の集計
- 管理者による各種設定
- 操作履歴

**含めない**
- OTA（楽天トラベル、じゃらん、Booking.com など）との連携
- 複数施設への対応
- 外貨での表示・決済
- レストランなど付帯施設の予約
- 経理・レストラン担当などの役割

**技術的な前提（業務ルールではない）**
- 決済は決済代行サービスのテストモード、または模擬実装を使う（確定）
- 技術スタックは設計フェーズで決める

**今後の改修**：MVP の後に検討する項目は [future-improvements.md](future-improvements.md) に記録する

## 6. 料金

### 6.1 計算ルール

| ID | 内容 | 状態 |
|---|---|---|
| PR-01 | 料金は**1人1泊あたり**の単価で計算する | 確定 |
| PR-02 | 子どもの単価は**基本料金**の半額。幼児は無料 | 確定 |
| PR-03 | 1泊ごとに計算する。割増は該当する夜にだけかける | 確定 |
| PR-04 | 割増・割引の率は**すべて合算**し、その合計を基本料金にかける（例：+20% −5% −10% = ×1.05） | 確定 |
| PR-05 | 1泊にかかる割増は1つだけ（金・土・祝前日・特定期間が重なっても重複させない）。率の違う割増が重なる夜には、**高いほうの率**を適用する | 確定 |
| PR-06 | 合算した率の下限は −50% | 確定 |
| PR-07 | 1人1泊の税抜単価に消費税10%をかけ、**税込単価の100円未満を切り捨て**てから、人数と泊数で合計する | 確定 |
| PR-08 | オプション（朝食など）は、子どもは半額、幼児は無料。割増・割引の率はかけない。税込単価の100円未満を切り捨てる | 確定 |
| PR-08a | 朝食は、大人・子ども・幼児ごとに朝食をつける人数を選び（各区分の人数以下）、全泊に同じ人数を適用する（2026-10-19 変更。夜ごとに変えたい場合は予約の変更で対応する）。アーリー・レイトは部屋ごとに選べる（予約時は全室同じ設定が初期値）。オプションは、「1人1泊あたり」の朝食と、「1室1時間あたり」のアーリーチェックイン・レイトチェックアウト（RS-17）を扱う。PR-08 の子ども・幼児の区分は朝食にだけ適用する。駐車場はオプションにしない（ホテルの駐車場が複数あり、近くに立体駐車場もあるため、システムでは管理しない） | 確定 |
| PR-08b | チェックインのとき、フロントは朝食の人数に応じた朝食券（紙）を渡し、宿泊客はそれで朝食会場に入る。システムは、渡す枚数を朝食の日付ごと・年齢区分ごとに表示する。券の印刷と会場での確認はシステムの対象外 | 確定 |
| PR-09 | 料金は予約確定時点の金額で固定する。後で料金表を変えても既存の予約には影響しない（変更時の扱いは CH-01 を参照） | 確定 |
| PR-10 | 通貨は日本円のみ | 確定 |

### 6.3 計算例（テストの基準値）

**条件**：基本料金 18,700円/人、土曜泊（+20%）、早期割（−5%※）、4名での人数割（−10%）、朝食 3,000円/人。大人2名・子ども1名・幼児1名、1泊・1室
※この例の率は計算方法を確かめるための仮の値です。

| 項目 | 計算 | 金額 |
|---|---|---|
| 率の合計 | +20 −5 −10 = +5% | ×1.05 |
| 大人の単価 | 18,700 × 1.05 × 1.1 = 21,598.5 → 切り捨て | 21,500円 × 2 |
| 子どもの単価 | 9,350 × 1.05 × 1.1 = 10,799.25 → 切り捨て | 10,700円 |
| 幼児 | — | 0円 |
| 朝食（大人） | 3,000 × 1.1 = 3,300 | 3,300円 × 2 |
| 朝食（子ども） | 1,500 × 1.1 = 1,650 → 切り捨て | 1,600円 |
| **合計（宿泊税を除く）** | | **61,900円** |

| PY-03 | 早期割は事前決済の場合だけ選べる | 確定 |
| PY-04 | 事前決済は予約時に全額を払う | 確定 |
| PY-05 | 現地払いの長期滞在は**7泊ごと**に精算する（8日目に1〜7泊目の分をフロントで精算し、以後も7泊ごと）。事前決済の予約は予約時に全額を払っているので対象外。※30泊ごとから変更：途中で客が来なくなったときの未回収額を小さくするため | 確定 |
| PY-06 | 事前決済では決済が完了した時点、現地払いでは会員が確定の操作をした時点（登録済みのカードをカード保証にする）で予約が確定する。決済待ちの間は在庫を**15分**確保し、時間切れになったら解放する | 確定 |
| PY-06a | 確保から確定までの間に条件（料金の版・特定期間割増・早期割の期限・当日予約の締め切り）が変わった場合は、**確定の時点の条件**で判定し直す。確保の時点に表示した額と変わったら確定せず、新しい額を示して確認を求める。当日予約の締め切りを過ぎていれば受け付けない（2026-10-20 確定、テスト設計 H-1） | 確定 |
| PY-07 | 通常料金：到着日のチェックイン時刻（15:00）の48時間前までは無料（ちょうどの時刻は無料側）。それを過ぎると1泊分（PY-11） | 確定 |
| PY-08 | 団体（5室以上）：30日前から20%、7日前から50%、前日から100%。基準額と境界は PY-12、PY-13 | 確定 |
| PY-09 | 早期割：返金不可 | 確定 |
